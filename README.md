DealHound — a Black Friday deal finder with 66 real, price-checked deals across 14 categories and 11 stores. Every deal carries its product, store, sale price, usual price, discount and when its price was checked, plus a signal saying whether it is really a deal (a new low, a strong price, or a routine sale, with the evidence). Search and filters by category, store, discount and signal all work, and the board works on desktop and on a phone. Every price was read at the store or in a deals roundup that names the store, 23–27 Nov 2026. Static files only — no network calls at runtime.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
